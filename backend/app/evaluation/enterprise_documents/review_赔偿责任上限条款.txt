# 赔偿责任上限条款
# 知识类型: contract
# 用途: Sprint 8.8 企业级合同知识库-合同审核规则

赔偿责任上限条款

一、赔偿责任上限条款（Liability Cap）的定义
赔偿责任上限条款约定一方违约或侵权时承担赔偿责任的最高金额，通常为合同总额的1-2倍或约定固定金额。
同时，责任限制条款通常排除间接损失的赔偿：利润损失、商誉损失、机会损失、业务中断损失等不纳入赔偿责任范围。

二、为什么重要
1. 控制商业风险：避免因单笔合同违约导致企业陷入重大财务危机；
2. 明确风险边界：让双方对最坏情形下的赔偿金额有清晰预期；
3. 促进交易：合理的责任上限使高价值交易更易达成；
4. 是企业合同风险管理的核心条款之一，与违约金条款、免责条款共同构成责任分配体系。

三、条款要点
1. 责任上限计算基数：通常为合同总价或已支付金额，常见为合同总额的1-2倍或固定金额；
2. 排除间接损失：明确排除利润损失、商誉损失、机会损失等间接损失；
3. 例外情形：故意或重大过失、侵犯知识产权、违反保密义务、人身损害等通常不适用责任上限；
4. 与违约金、定金的关系需明确约定。

四、企业实务提示
1. 作为买方，应尽量争取较高的责任上限并保留间接损失索赔权；
2. 作为卖方，应通过责任上限控制无限赔偿责任；
3. 审查责任上限的例外条款，确保重大风险（如数据泄露、知识产权侵权）不被排除在外。
