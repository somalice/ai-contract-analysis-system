# 招投标基本规则与投标文件要求
# 知识类型: bid
# 用途: Sprint 8.8 企业级合同知识库-招投标规则

招投标基本规则与投标文件要求

一、招投标基本流程
招标公告/邀请 → 投标人获取招标文件 → 投标人编制并递交投标文件 → 开标 → 评标 → 定标 → 发出中标通知书 → 签订合同。
依法必须招标的项目（大型基础设施、公用事业、使用国有资金等）须依法进行招标，不得化整为零规避招标。

二、招标文件的主要内容
1. 招标公告或投标邀请书；
2. 投标人须知（投标资格、投标保证金、投标有效期、投标文件的编制与递交要求）；
3. 项目需求/技术规格：项目名称、技术要求、时间要求、评分标准；
4. 合同主要条款（付款、验收、违约责任、争议解决）；
5. 投标文件格式要求。

三、投标文件的要求
1. 实质性响应：投标文件须对招标文件的实质性要求和条件作出响应，否则可能被认定为无效标；
2. 资格条件：具备招标文件要求的资质、业绩、财务状况；
3. 报价合理：不得高于最高限价，不得低于成本报价；
4. 形式要求：按招标文件规定的格式、签署、密封递交。

四、评标与定标
评标委员会按招标文件确定的评标标准和方法（综合评分法/经评审的最低投标价法）评审；
定标后发出中标通知书，双方应在规定期限内（通常30日内）签订书面合同，不得再行订立背离合同实质性内容的其他协议（避免黑白合同）。

五、企业实务提示
投标企业应完整研读招标文件，重点核对：资格条件、实质性条款、时间要求、评分标准，确保投标文件实质性响应且在规定时间内递交；中标后及时签订合同。
