# 保密协议权利义务与例外
# 知识类型: contract
# 用途: Sprint 8.5 AI 评估测试知识库

保密协议权利义务与例外

一、接收方义务
1. 按最小必要原则接触保密信息，仅用于约定目的；
2. 采取与保护自身类似信息相同的合理措施保护保密信息；
3. 不得向第三方披露保密信息（除必要的员工、顾问且其签署保密承诺）；
4. 不得复制、传播保密信息，确需复制的应标注保密标识；
5. 协议终止或披露方要求时返还或销毁保密信息及其载体。

二、披露方权利
1. 要求接收方采取保密措施；
2. 监督接收方使用保密信息的情况；
3. 协议终止后要求返还或销毁保密信息；
4. 接收方违约时要求停止违约、赔偿损失。

三、强制披露例外
因法律法规、法院命令、政府监管要求必须披露保密信息的：
1. 接收方应提前书面通知披露方（法律允许的范围内）；
2. 仅披露法律要求的最小范围信息；
3. 配合披露方寻求保护令；
4. 已依法披露的信息在披露范围内不再承担保密义务。

四、知识产权保留
保密信息的披露不构成知识产权的转让或许可。披露方保留所有专利、商标、著作权、商业秘密等权利。
接收方不得将保密信息用于申请专利或登记著作权。

五、违约责任
违反保密义务的违约责任：
1. 支付违约金；
2. 赔偿实际损失（包括利润损失、调查费用、律师费）；
3. 停止违约行为、返还保密信息；
4. 情节严重的承担刑事责任（侵犯商业秘密罪）。
