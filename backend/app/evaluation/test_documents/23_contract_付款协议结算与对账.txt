# 付款协议结算与对账
# 知识类型: contract
# 用途: Sprint 8.5 AI 评估测试知识库

付款协议结算与对账

一、结算方式
1. 现结现付：交付同时付款；
2. 定期结算：按月/季汇总结算；
3. 滚动结算：每次交付后滚动结算前期款项；
4. 竣工结算：建设工程竣工后一次性结算。

二、对账流程
1. 收款方提交对账单（含交付明细、金额、发票）；
2. 付款方在约定期限内（通常5-15个工作日）核对确认；
3. 异议部分双方协商解决；
4. 确认无误后付款方按约定支付。
对账确认书是重要结算凭证，应妥善保存。

三、工程结算
建设工程竣工结算：
1. 承包方提交竣工结算报告及资料；
2. 发包方在约定期限内（通常28-56天）审核；
3. 审核确认后支付结算款（通常付至95%，留5%质保金）。
工程量偏差、设计变更、现场签证、索赔费用均纳入结算。

四、发票与税务
付款协议应明确：
1. 发票类型：增值税专用发票（可抵扣）或普通发票；
2. 税率：13%（货物）/9%（建筑运输）/6%（现代服务）；
3. 开票时间：付款前或付款后；
4. 开票信息：名称、税号、地址电话、开户行账号。
增值税专用发票应在开具后360日内认证抵扣。

五、跨境付款
跨境付款协议涉及：
1. 外汇管理：经常项目/资本项目，需符合外汇监管；
2. 结算货币：人民币/美元/欧元，约定汇率基准；
3. 付款路径：跨境支付需通过银行，涉及反洗钱审查；
4. 税务：代扣代缴增值税、预提所得税。
