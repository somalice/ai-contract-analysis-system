# 采购合同付款方式与验收标准
# 知识类型: contract
# 用途: Sprint 8.5 AI 评估测试知识库

采购合同付款方式与验收标准

一、常见付款方式
采购合同常见付款方式包括：
1. 预付款：合同签订后支付10%-30%；
2. 进度款：按里程碑或完工百分比支付；
3. 验收款：交付并验收合格后支付至90%-95%；
4. 质保金：5%-10%在质保期满后支付；
5. 一次性付款：适用于小额简单交易；
6. 信用证/银行承兑汇票：适用于大额贸易。

二、质保金
质保金（质量保证金）用于约束卖方在质保期内履行维修、更换、退货等质量义务，防止交付后卖方逃避责任。
质保金比例通常为合同总价的5%-10%，质保期一般为6个月至2年，质保期满无质量问题则无息退还。

三、付款节点
付款节点是与交付里程碑挂钩的付款触发条件。采购项目典型节点：
1. 合同签订：预付20%-30%；
2. 到货签收：付40%-50%；
3. 验收合格：付至95%；
4. 质保期满1年：付剩余5%质保金。

四、验收标准
验收标准分为：
1. 形式验收：数量、规格、包装、单据核对无误；
2. 功能验收：按技术规格书逐一测试功能点；
3. 性能验收：响应时间、并发量、稳定性等指标达标；
4. 试运行验收：上线运行7-30天无重大故障。
合同中应明确验收方法、验收主体、异议期（通常7-15天）、不合格处理流程。

五、交付条款
交付条款通常包括：交付时间、交付地点、交付方式（现场/邮寄/线上）、交付清单、包装要求、
运输方式及费用承担、风险转移节点（装运港/目的港/签收后）、签收流程与异议期。

六、逾期付款违约金
逾期付款违约金通常按日计算：每日万分之三至万分之五，同时设置上限（通常不超过未付款总额的5%-10%）。
违约金过分高于实际损失时，法院可依《民法典》第585条酌情调减。
