# 服务合同终止与争议解决
# 知识类型: contract
# 用途: Sprint 8.5 AI 评估测试知识库

服务合同终止与争议解决

一、合同终止情形
1. 服务完成验收合格，合同义务履行完毕；
2. 双方协商一致解除；
3. 一方根本违约，守约方解除；
4. 不可抗力致合同目的不能实现；
5. 约定解除条件成就。

二、合同解除后果
合同解除后：
1. 尚未履行的服务终止履行；
2. 已经履行的按情况恢复原状或采取补救措施；
3. 已完成服务部分应支付相应费用；
4. 违约方赔偿守约方损失；
5. 保密义务、争议解决条款在合同终止后继续有效。

三、争议解决方式
服务合同争议解决：协商、调解、仲裁、诉讼。
仲裁一裁终局，约定仲裁应明确仲裁委员会。诉讼管辖可约定被告住所地、
合同履行地、合同签订地、原告住所地、标的物所在地法院。

四、适用法律
国内服务合同适用中华人民共和国法律。涉外服务合同可约定适用法律，
涉及中国强制性规定和公共利益的适用中国法。

五、通知与送达
合同应约定通知送达方式（书面、邮件、快递）、送达地址、送达视为成立的条件。
电子送达（邮件、即时通讯）在约定情况下具有法律效力。

六、合同份数与效力
服务合同一式若干份，双方各执一份，具有同等法律效力。
合同附件（服务说明书、SLA、技术规格书）与正文同等效力，冲突时按约定优先级解释。
