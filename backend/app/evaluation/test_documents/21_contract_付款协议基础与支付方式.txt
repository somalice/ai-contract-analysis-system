# 付款协议基础与支付方式
# 知识类型: contract
# 用途: Sprint 8.5 AI 评估测试知识库

付款协议基础与支付方式

一、合同基础信息
付款协议是合同双方就款项支付事项达成的专项协议，可作为主合同附件或独立协议。
协议基础信息要素：协议编号、协议名称、签订日期、付款方与收款方名称、
统一社会信用代码、法定代表人、注册地址、联系方式、开户银行及账号。

二、常见付款方式
付款协议常见付款方式：
1. 预付款：合同签订后支付10%-30%，用于启动准备；
2. 进度款：按里程碑或完工百分比支付；
3. 验收款：交付并验收合格后支付至90%-95%；
4. 质保金：5%-10%在质保期满后支付；
5. 一次性付款：适用于小额简单交易；
6. 信用证/银行承兑汇票：适用于大额贸易。

三、支付工具
1. 银行转账：最常用，留痕清晰；
2. 电子支付：第三方支付、网银支付；
3. 票据支付：支票、汇票、本票；
4. 信用证：国际贸易常用，银行信用担保；
5. 现金：小额即时交易，受现金管理规定约束。

四、付款节点设置
付款节点与交付里程碑挂钩：
- 合同签订：预付10%-30%；
- 中间交付：按进度付40%-60%；
- 验收合格：付至90%-95%；
- 质保期满：付剩余5%-10%质保金。

五、发票管理
付款协议应约定发票类型（增值税专用发票/普通发票）、税率、开票时间、开票信息。
增值税专用发票可抵扣进项税，应在开具后规定期限内认证。
